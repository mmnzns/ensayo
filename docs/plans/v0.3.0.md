## Decisions this plan makes (Miguel can overrule at stop point 1)

1. **Claude API version stays `2023-06-01`.** The newer `2026-10-21` rejects `temperature` on every model, and Ensayo still sends it to older Claude models. Adding `output_config` (effort and format) under 2023-06-01 is tried first. If the live test returns a 400, Task 1.3 falls back to the text schema for Claude, and that is reported.
2. **Gemini structured output is last and behind a fallback.** Gemini's schema subset is the narrowest. If its schema mode refuses a schema, the call goes on the text path, as today.
3. **"Resume a session after quitting" (B) is saved as a light version:** the questions asked and the reps already saved are kept, and Home offers "Continue where you left off" with the next question. A mid-answer state is not restored, because the recording is already handled by the stray-recording fix (A21).
4. **Trash for stories and applications (B)** reuses the session trash (7 days, Restore in the same list). Applications also move their resume file and notes.
5. **Search (B)** is one box per list, filtering on titles and companies only, on the frontend. No full-text index.
6. **Pause while recording (B)** pauses the capture: the WAV stops growing, the clock stops, and the 4-minute limit counts recorded time only.
7. **Fix a mis-heard word (B)** edits the words of the transcript on the result screen, then rescores with the edited text. The audio is unchanged, and the rep records that the transcript was edited.
8. **Default data folder (W1):** stop point 3 decides. Proposed: new installs use `Documents/Ensayo` on both systems. An existing install whose data is in the old default folder sees a one-time card on Home, "Move your data to Documents › Ensayo", which uses the existing Move… code. Nothing moves without a click.
