**What's new in 0.5.1**

**Recording**
- Fixed: Record could get stuck on "Already recording", and Try again failed the same way until Ensayo was restarted. Two starts could reach the microphone for one question. Now only one starts, and a recording left running with nothing on screen is taken over instead of blocking you.
- Start over is now a round button right next to Stop, with the key R. The small link in the corner is gone.
- Skip question while you answer, with the key S. It throws the recording away, saves nothing and uses no AI, then moves to the next question. Not in a Mock, where the interviewer picks the questions.

**Practice questions**
- An application's practice no longer asks the same thing twice in different words. Reading a posting folds a gap into the question that already covers it, and a session drops near-repeats. General questions are skipped when the application already has its own question of that kind. Applications you already have get this without a Recheck.

**Faster answers**
- With OpenAI, every answer used to send its scoring request twice, because the first one was refused. The request is now in a form OpenAI accepts, and if a provider ever refuses it, Ensayo remembers that for the rest of the session.
- The check against what you said in earlier stages now runs while the coach writes, not after it.

**Speech**
- Settings › Speech and the setup speech step show each model's speed and accuracy, where it runs on this computer (graphics card or processor), and what it's good for.
- Windows: Whisper now runs on the graphics card through the engine's speech helper when you have a dedicated card and Use the graphics card is on. It falls back to the processor if the card can't be used. With integrated graphics only, speech runs on the processor.

**Fixes**
- Profile › a target › Base resume: a long file name no longer breaks into one letter per line. The same fix applies to the data folder row in Settings › Privacy.
